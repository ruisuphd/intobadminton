# Noindex inventory

A record of every URL on `intobadminton.com` that intentionally emits
`<meta name="robots" content="noindex">`. Maintained so that Google Search
Console alerts about "Excluded by 'noindex' tag" can be triaged quickly
against this list — if the affected URL is in this file, the exclusion is
intentional and the GSC "Validate fix" / "Mark as expected" action is the
correct response.

Last audited: **2026-08-14**. Every noindex URL is omitted from `sitemap.xml`
(no mixed signals). Spec PDPs and thin court notes also have ads off;
`noindex` does not hide a URL from AdsBot.

## 1. Spec product pages (all `/product/[id]/`)

Every catalogue spec PDP is `noindex, follow`. They stay live for the finder,
compare tray, and catalog. They are not expanded in `src/lib/sitemap.ts`.

**Rationale.** These pages are generated spec sheets. They are not the
publication Google should inventory for AdSense.

Declaration: `src/app/product/[id]/page.tsx` (`robots: { index: false, follow: true }`).

## 2. Review URLs held back by `src/lib/thin-content.ts`

The live list is computed from the corpus. Do not hand-maintain a slug dump
here. `noindexReviewSlugs` is the union of:

| Reason | Source | What it is |
|---|---|---|
| Thin / unoriginal | `thinContentNoindexSlugs` | Body under ~800 words **or** not original editorial / founder-firsthand |
| Duplicate SKU | `duplicateNoindexSlugs` | Weaker twin of a kept review |
| Consolidated SKU | `consolidatedNoindexSlugs` | Overlapping sibling; 301 in `retiredRedirects` on static export |

Indexed reviews are original editorials (`ORIGINAL_EDITORIAL_SLUGS`) or
founder-firsthand product maps, and they clear the length gate. Imported
forum translations are not padded to pass that gate.

As of 2026-08-14: **26** indexable `/review/<slug>/` URLs, **183** noindex
review URLs, corpus **209**.

Declaration: `src/app/review/[slug]/page.tsx` via `isThinContentNoindex`.
Ads: `adsAllowedOnReview` (same gate). Sitemap: `indexableReviewSlugs`.

## 3. Legacy locale redirects (66 URLs)

Generated by `scripts/generate-legacy-redirects.mjs` from
`src/data/legacy-redirect-destinations.json`. Each redirect page emits
`noindex, follow` plus a `<meta http-equiv="refresh">` to the canonical
unlocalized URL plus a `<link rel="canonical">` to the same destination.

- `/en/` and 32 child paths (e.g. `/en/about/`, `/en/blog/`,
  `/en/guides/string-tension/`)
- `/zh/` and 32 child paths (Chinese-language URL deprecation)

**Rationale.** The site was originally bilingual with `/en/` + `/zh/`
prefixed routes. After the locale system was simplified to English-only,
these URLs were preserved as proper `noindex + canonical + meta-refresh`
redirects so Google's index can transition cleanly.

## 4. Operational / user-state pages

These render per-device or per-session state, or are pure form / utility
pages with no useful content for a crawler.

| URL | Why noindex |
|---|---|
| `/results/` | Per-user finder output, computed from the query string / saved profile |
| `/setup/` | Operational page, not a landing surface |
| `/compare/` | Empty compare-tray surface (state lives in `localStorage`) |
| `/review/submit/` | Submission form |
| `/privacy-choices/` | Operational consent surface |
| `/blogs/` | Legacy path; redirects to `/blog/` |
| `/saved/` | Per-device shortlist (depends on `localStorage`) |

## 5. Framework / 404 pages

| URL | Why noindex |
|---|---|
| `/404` | The 404 page itself |
| `/_not-found` | Next.js framework fallback |

## What to do when GSC sends a "noindex" exclusion alert

1. Open the GSC alert and note the affected URL(s).
2. If it is `/product/<id>/`, a slug in `noindexReviewSlugs`, a legacy
   `/en/` or `/zh/` redirect, or one of the operational/404 rows above, the
   exclusion is **intentional** — dismiss or mark as expected.
3. If the URL is **not** in those buckets, the noindex is unintentional.
   Check `generateMetadata` on the route. Dynamic `[slug]` fallbacks use
   `index: false` for unknown slugs; `generateStaticParams` should prevent
   that at build time.
