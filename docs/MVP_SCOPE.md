# MVP scope (locked for v0.1)

| Area | Decision |
|------|-----------|
| **Category** | Rackets only — shoes, string, grip, bag use same funnel pattern later. |
| **Locale** | English UI; currency display USD for demo prices. |
| **Monetization** | AdSense-ready reserved slots; affiliate hooks not wired in code (disclose in legal when used). |
| **Auth** | None — profile, compare, and history use `localStorage` only. |
| **Hosting** | Static export (`next build`); see [DEPLOY.md](./DEPLOY.md). |
| **Data** | Curated JSON catalog + documented source policy; no live crawl in MVP. |

Review when traffic and editorial capacity justify Phase 2 (accounts, more categories, ingestion jobs).
